# Decisions

- **Training metadata:** either reuse the accepted configuration or require the candidate's authenticated configuration, preparation, data receipt and source seal. Default: require the candidate closure and run the unchanged restoration checks. The supplied direct-reader package contains no authenticated candidate training closure. Packet admission must refuse until it is supplied.
- **Native arm:** either change kernel files or select the native serving prefix at C8r's existing AST boundary. Default: preserve all C8r source bytes and add an explicit worker selector. The selector checks the exact scripted suffix before excluding it; it keeps the entire native prefix and replay checks.
- **Items:** use the supplied frozen distance list. An expanded list requires its own digest, complete reference records and shared-order admission; the current backend refuses an unimplemented extension.
- **Proof selection:** use the deterministic type/unit quotas and membership recorded in `ITEM_SELECTION.json`. Keep exact reference records as pinned evidence.
- **Canary:** decode the fixed membership in `ITEM_SELECTION.json` once and reuse those rows in the full result. Persist and publish its receipt before decoding the remaining items.
- **Names:** rename operational asset paths and item keys reversibly. Do not rewrite hash-bound preparation or kernel metadata silently. Any remaining job-visible name is a release blocker, listed in `NAMING.md`.
- **Namespace failure:** retain the failed namespace probe and provide operator commands. Run logic tests and recorded-row orchestration locally. Never describe recorded rows as a whole-worker model rehearsal.
- **Submission:** create a review package with explicit release blockers. Do not manufacture review authority, cloud generations, candidate metadata or successful GPU proof.
- **Resource estimate:** use measured native item timings, not half of paired wall time. C8r's other arm executes scripted tools, so a factor-of-two speedup is unsupported.
- **I/O:** reuse read-only local assets; avoid bulk archive expansion, large copies and installations. All generated artifacts remain in this build.
