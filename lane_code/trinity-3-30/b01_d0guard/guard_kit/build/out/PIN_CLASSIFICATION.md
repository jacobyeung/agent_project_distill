Export-independent means that backend bytes and check semantics stay fixed. Fresh tokens, job IDs, payload seals and new code-object hashes cannot literally equal the accepted invocation. Those build/invocation exceptions are explicit below; treating them as unchanged pins would be false. `BASELINE_PIN_VALUES.json` records every scalar CONFIG/FAMILY value, and `PIN_CLASSIFICATION.json` carries each complete baseline object.
