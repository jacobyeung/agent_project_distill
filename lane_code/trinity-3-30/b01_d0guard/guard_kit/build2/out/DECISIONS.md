# Decisions

- Closure: authenticate the supplied files and preserve their signed bytes, or rewrite nested metadata. Default: preserve signed bytes and validate through the unchanged trainer and restoration code. Neutral aliases must not silently change authenticated identities.
- Process isolation: reuse a loaded model or start one process per checkpoint. Default: separate processes, because the gravity guard installs once.
- Canary: decode twice or retain its rows. Default: retain rows and require successful receipt publication before reading the tail.
- Rehearsal: claim recorded rows as a worker run or identify model boundary stand-ins explicitly. Default: use the supplied C8r boundary and mark every synthetic result; namespace failures remain blockers.
- Launch: allow missing authority or require exact family, plan, review and ORCH GO bindings. Default: refuse missing or stale bindings.
- Naming: preserve sealed kernels and map boundary names, or silently rewrite kernel bytes. Default: preserve kernels; any unresolved operational name remains an explicit blocker.
- Time: finish the requested integrations within the build window, or ship tested components with explicit blockers. Default: stop within the deadline and report unverified work accurately.
- Naming scope: keep every trainer member and signed metadata byte identical, or change those names and re-derive the identities. Default: preserve the required source identity and keep release blocked where the names remain visible. The exact source-tree invariant covers `trace_format/vsi_scannet_vocab.json` (`out/NAMING.json`); silently omitting it would weaken admission. Outer candidate archive names are neutral and round-trip byte-exact (`out/NAME_ROUNDTRIP.json`).
- Subset report: pad the subset with unexecuted records, or let the unchanged report reject missing items. Default: run the report on the actual subset and expect an incomplete-read refusal. The separate full recorded-row report fixture has its own label (`out/rehearsal/records_pass/RESULT.json`).
- Rehearsal authority: manufacture a successful production packet, or keep model/transport fixtures separate from launch authorization. Default: explicit fixture controls and no production authority. Packet emission tests use fabricated authority only inside retained unit-test directories (`out/PACKET_TEST.json`).
- Batch transport: embed the entire input archive in the Slurm script, or pin an external neutral payload path with a literal digest. Default: pin `p.tar` and `m.tar` under the token's neutral Orchard directory. This keeps the batch script small while authenticating every byte before execution (`out/guard_kit/packet.py`).
- Stream admission: seek through every input, or retain the unchanged streaming extractor's link rejection and preflight only the runtime archive that admits symlinks. Default: preflight only that seekable archive. Frame streams remain non-seekable and hard links remain refused (`out/guard_kit/staging.py`, `out/g2_tests_integration.log`).
- Rehearsal canary: take the first subset rows, or preserve the sealed canary membership. Default: preserve the sealed membership and refuse a subset that omits any canary item (`out/guard_kit/checkpoint.py`).
- Phase lifecycle: duplicate orchestration in the CPU runner, or call the production coordinator through explicit boundary adapters. Default: share the coordinator; record staging and allocation differences as unresolved rehearsal coverage (`out/guard_kit/worker.py`, `out/rehearsal/run_whole_worker.py`).
- Receipt transport: wait through long cloud timeouts, or bound cloud attempts after a verified result-pool copy. Default: bound cloud attempts and reserve return time so early receipts can be acknowledged promptly (`out/guard_kit/transport.py`, `out/SIZING.json`).
