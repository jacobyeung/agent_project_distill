# RFT-1 design record

**Question.** Can a call-writing student supply additional supervised programs whose answers depend on their own tool outputs, with enough preparation that a later GPU run needs no kit debugging?

**Answer.** The kit implements free routed sampling, durable resume, benchmark scoring, operand provenance, CPU counterfactuals, selection and v3.13 row writing. CPU tests establish the software contracts. They do not establish the checkpoint's keep rate, routed throughput, GPU fit or benchmark improvement.

**CPU evidence.** All 50 tests pass in 16.85 seconds on trinity-2-18 with CUDA hidden. [CPU_TESTS.json](CPU_TESTS.json) records the command, source hashes and retained native/card evidence. One upstream NumPy deprecation warning remains.

## Evidence and decisions

| Question | Decision | Evidence |
|---|---|---|
| Which decoder owns inference? | Wrap `student_pilot.carrier_c1_decode.generate`. | The integrated acceptance scripts use this path and its v3.13 response session; `headcall/decode.py` is the older interface. Native CPU fixtures execute the current path. |
| Where does the answer key come from? | Require recomputed-exact-frame GT with authority, frame indices and RGB file hashes. | The plan excludes known released-label convention defects. Mutation tests reject release labels, frame mismatches, RGB mismatches and nontraining/guard-set items. |
| Does a correct answer suffice? | Require score, provenance and a changing CPU replay. | Correct arithmetic passes; correct guesses with untraced operands, answers detached from their computation, constant-only computations and routed prior guesses fail. |
| What does counterfactual replay mean? | Re-run native calculators over scaled/reflected or swapped tool operands and the same restricted final projection. | Tests cover multistep arithmetic, printed distances, direction options, nearest-object labels and full-precision audited box gaps. |
| Can box measurements use rounded public boxes? | Require original private boxes and sampler metadata. | The v3.13 box tool measures private boxes. Tests authenticate their public serialization, replay their gap and reject missing private audit state. |
| What does an abstention earn? | Score the completed fallback; require a trainable answer binding before writing. | A correct fallback receives score 1.0 in the test. The abstention itself cannot supply a supported final-answer dependency and produces no row. |
| How are answer priors measured? | Fit one constant per type on the training pool with the existing benchmark scorer; report semantic option values and ambiguous/other strata. | Tests isolate items that the fitted constant answers correctly and reject a nontraining fit. ReVSI never enters fitting or sampling. |
| How does selection protect the stream? | Deduplicate within each question, equalize type counts and match frozen answer-bin shares. | Tests show duplicate removal, exact 50/50 selection, WAIT below 20%, and WAIT when a bin or type is absent. |
| What training contract is written? | Current C1 routed rows, revision 3.13, rendered events and response spans. | The tree's validator and SQLite row loader accept the rows; its suffix masker masks every tool response. GO/WAIT CLI tests check row-file publication and denominator reports. |
| What survives an interruption? | Atomic, checksummed commits per draw with seed derived from question and draw index. | Tests interrupt within a question, preserve committed bytes, repeat only an unfinished draw and reject changed inputs/configuration. |

The CPU evidence also covers all 64 recorded r15 card streams and four distinct exact-token continuations through tiny native Qwen3.5 forwards. The recorded streams contain scripted call prefixes and model continuations; they are infrastructure fixtures. Three streams have unlogged computations and fail structural admission. Native continuation tests substitute recorded choices and the recorded extra box replies. They make no claim about learned free-sampling quality.

## Options rejected

- An answer-only reward or a subtracted per-type constant cannot deny a lucky answer-prior guess. The plan requires gated admission.
- Released labels with defective conventions cannot replace exact-frame GT. Missing authority data blocks production sampling.
- A new decode loop would duplicate tool insertion and cache semantics. The wrapper retains the integrated decoder.
