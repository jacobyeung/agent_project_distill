What might not hold: Available GT covers only 93 of 224 captures, so these scores need not represent the entire dev distribution. The GT-naive “ceiling” is an empirical reference, not a mathematical upper bound: its visibility and vocabulary errors remain. The reviewed ScanNet++ counting item has two chair labels and four office-chair labels, but the matcher returns only two. Four reviewed abstentions arise from operands below 154 pixels. ARKit sensor/box-assigned masks differ from dense manual masks. Sparse views and frozen trimming can remove object extent. Scene clustering can overstate precision for related captures. Mixed g3s32/g3s64 groups retain a scale rule fitted on g3s64. Large room-area errors can survive small median depth errors; joint geometry swaps do not establish the separate causes.
