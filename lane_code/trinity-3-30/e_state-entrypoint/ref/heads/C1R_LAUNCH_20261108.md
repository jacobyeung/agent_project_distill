# C1-r launch record (c1r lane, 2026-11-08)

C1-r runs as job 108986 (8 GPUs, started 16:00Z) with resume leg 109024 queued afterany. It tests whether the G3T teacher package speeds pose learning against C1-a.

## What C1-r is
- C1-a's recipe: placement a (one local CAM after each duplicate temporal group), duplicate layout, 32 viewpoints, trajectory_balance false, the same recipe, LR horizon and 800 steps.
- Plus the G3T package: 2H zero-bias projector whose output feeds the pose head; 0.5 x (1 - Pearson r) per CAM and 0.5 x (1 - clip CCC) over CAMs 2-32 against layer-23 G3T camera tokens; pose head initialized from G3T's global camera head with the first-pass pose embedding folded in; copied trunk at 1e-5, new parts at 1e-4.
- Trainer 9f6c1dee (branch c1r-g3t), kit 19dea3f3, config 967b8919, AWS output ap/c5b61f35/o/f60e3512.

## Confounds against C1-a
1. The teacher terms and the projector-fed head.
2. The head init and LR split.
3. Anchor sampling: C1-r reads 25,600 dense-plan clips over the same 3,540 A1 recordings (anchors uniform over 224 dense frames per recording, anchor 1 = first posed frame), not C1-a's A1 rows, so rows, frames and order differ. Only same-row loss ratios or the shared 38-scene readout compare the arms.
4. Trainer code: C1-r branches from the C1 base 1db21600; C1-a runs 6f974710.

## Launch facts
- Store: 3,540/3,540 recordings indexed in 443 shards, 32/32 chunk receipts PASS.
- The loader verifies each record header against the shard index and hashes every array it reads, but never rehashes whole shard blobs and never reads the patch arrays (no patch term). This removes ~1.5 TB of Lustre reads per rank per leg.
- Train needs no guard, smoke, timing, review or coverage receipt; preparation runs inside the job; each train leg resumes from the newest complete A/B slot, so resume legs are plain train jobs chained with afterany.
- The teacher pin must equal the store binding's teacher byte for byte. The cache recorded the G3T source tar at its sandbox path, so the trainer's pin copies that record.
- Kit pushes use governor priority 0: at priority 1 a small kit waits behind a long priority-1 bulk copy.
