# Grounding-head pilot: the full-label data path on CPU (own_head r11)
Paths are on trinity-2-18 unless stated. Lane: pilot_dbg (Devin, Opus max), 2026-11-11.

## Question
The r10 pilot stopped in step-0 validation on trinity-1-8 with `ValueError: Admission name mismatch: scannet/scene0211_01|15|31` (validate.py:227, ogd/admission.py:127). Why do the admission file and the teacher labels name that key differently, how many keys disagree, and what is the join rule? What else on the full-label path would stop a card job that the CPU checks never reached?

## Answer
- **Cause.** label_ops admission rows (`p3c/O1_VAL_ADMISSION.jsonl`, `p3b/O1_ADMISSION.jsonl`) keep the raw O1 instance names. The teacher names every label row and census pair through its pinned normalization (`ttower/work/sam3/common.py`, `phrase()`: lowercase, underscores to spaces, collapsed whitespace, a fixed singular map). Each label manifest records that file's SHA256 as `provenance.normalization_sha256` (`6cac06b3…`). For the failing key, admission says `books` and the teacher's MISS row says `book`; `admission_views` compared the raw strings.
- **Same object.** Every disagreeing visible row shares scene, slot, instance ID and frame SHA256 with its teacher row, and its names agree after the teacher's normalization. No row disagrees after normalization, and no frame hash disagrees.
- **Rule.** Both sides join through the teacher's normalization (`work/ogd/names.py`, a copy that a test checks against the pinned teacher file). `admit()` refuses a manifest with another normalization hash or with names the rule would change. Instance rows join by scene, slot and instance ID and must agree on the normalized name. Absent rows join by their normalized name. A verdict that names another object after normalization leaves its row unjudged, outside the keep view, counted (`name_conflict_unjudged`) and listed (`admission_conflicts`). Two spellings of one absent query merge when their judgements agree; otherwise the row is unjudged and listed. A frame-hash mismatch fails.
- **Second card failure on the same path.** With the name fix alone, the pilot would stop at First20 update 4. Its batch (scannetpp/7fb8ff20e9: rj45 outlet, shoes, table lamp, window) carries no selector target by the label design: two names are MISS-only (selection weight 0) and two have several visible instances (ambiguous identity). Update 20 (scannetpp/cb7785f6ad) is the same. First20 now records the supervised-name count of each update and fails only when no update has one; the selection-term check stays.
- **Prepare covers the data paths.** Prepare now joins every validation row any frame choice can score (all 40 scenes, all three views and keep cohorts) with the admission verdicts, checks teacher-shortlist assembly and intended identity for every clip and name, plans the pilot's own first 20 batches through the real `prepare_batch` and `selection_batch`, and decodes every RGB frame. The cache records these audits; the pilot refuses a cache without them and a label transport the full-label CPU gate did not run.

## Options rejected
- Drop the name check and join on instance ID and frame alone: the name check is the only guard against a verdict about another object at the same ID; it stays, through the normalization.
- Normalize only the admission side: one function on both sides keeps the join symmetric; `admit()` also refuses labels the rule would change.
- Import the teacher's `common.py` at runtime: it adds a staged input on the card node and executes another lane's module. The copy is checked against the pinned file by a test and bound to the manifest's hash at admission.
- Fail on spelling collisions: the one val collision has identical judgements, so failing would block the pilot on a duplicate the data resolves. Choosing one of two disagreeing verdicts by file order would change a verdict silently.
- Resample names so every First20 batch has a selector target: that bends the training distribution to fit an assertion. Keeping the per-update rule stops the card at update 4.
- Keep the CPU gate on the three-scene smoke transport: that sample never reached a spelled row or update 4.
