# Geometry backend candidates

Read date: **2026-11-11**. Sources below are papers, official repositories or official model cards. Unknown values remain unknown. A published result on another GPU does not establish a 49 GB Trinity measurement.

## Comparison rules

- Every production model sees the exact 64 reconstruction frames, never a 32-frame fit. Only then does the exporter select the tower's exact 32 anchor ordinals.
- Metric monocular models retain G3T pose for the depth-only arm. Multi-view models also get a full pose-and-depth arm.
- Every full-pose arm uses the same frozen, predicted reference gravity. No GT scale, focal length, pose or gravity enters inference.
- Clip-scale hybrids fit one candidate/G3T depth ratio and apply it to both depth and translation. A separately named depth-only scale diagnostic distinguishes the two effects.
- Per-frame affine hybrids change depth only. The ensemble averages two candidates' optical depths on the same image raster and retains one fixed pose source; it does not average unaligned world points.
- The common 51 x 51 export can hide a native boundary gain. Report both native-raster metrics during export and the exported-grid metrics used by the programs.
