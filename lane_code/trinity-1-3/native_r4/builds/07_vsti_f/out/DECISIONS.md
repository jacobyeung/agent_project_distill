The build changes only return handling and packet archive admission. Successful returns preserve existing artifact bytes. Return assembly uses hard links to avoid duplicating large files on job-local storage; logs in a minimal return retain their last 2 MiB. The fallback uses the authenticated publisher, token, binding and channels. If /tmp cannot hold the fallback, an independent /dev/shm directory holds it. No fallback can guarantee delivery after SIGKILL, exhausted independent storage, or failure of both remote channels.
