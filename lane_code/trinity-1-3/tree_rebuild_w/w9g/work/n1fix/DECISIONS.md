# Build n1fix decisions

| Open choice | Options | Default in force |
|---|---|---|
| Donor evidence | Trust an operator progress receipt; or derive progress from the export-bound config and native run/preparation records | Derive every comparison from donor records. Refuse missing files by name. |
| Different donor and target row plans | Infer equivalence; refuse all differences; or require an explicit mapping in the target config | Require a SHA-bound mapping of the complete derived source and target identities. The mapping cannot supply sampler positions or override the LR schedule check. |
| Unsupported donor sampler | Guess its positions; or require producer evidence | Refuse with the sampler blocker. The supported sealed sampler replays its recorded mode, counts, mix and world size with its own fixed default seed. |
| Real P deployment | Guess deployment pins; or wait for real bytes | Keep real handover unqualified. The supplied parent-start path remains available; no donor pin is invented. |
| Fresh temporary namespace with pre-staged inputs | Accept an operator freshness flag; require all inputs in memory; or issue a token when the code creates the directory | create_job_tmp creates the private directory and issues a process-local, one-use token bound to its device and inode. frame_host consumes that token after inputs have been staged. Direct calls may instead create an absent directory. Local tests substitute a workspace namespace for the production temporary mount. |
| Complete-store evidence | Run another full census; or retain authenticated supplied results and test bounded slices | Retain the review and build receipts. Run no full-store census and copy no model, database or frame assets. |
| Suite resume | Repeat every test after a host-only change; or qualify changed dependencies and retain bound unaffected groups | Rerun the host tests and R2 group. Retain other groups only after source, test, fixture and runner checks establish that changed modules were not executed or directly imported by their tests. Record the inventories and source receipts. |
| Archive format | Drop inputs; or compress the complete review package | Use gzip-compressed tar with the requested filename suffix. Record stored and member sizes in DELIVERY.json. |
