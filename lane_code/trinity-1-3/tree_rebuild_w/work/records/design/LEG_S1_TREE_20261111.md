## Options rejected

- **Program rows for direct-default types:** those forms do not implement this leg's approved table.
- **A full training flag:** another lane owns that design for a later leg. This leg cannot claim trained forced-direct versus forced-program comparisons or the corresponding R1b/R2 tests.
- **Per-type camera reweighting:** the sampler has no such configuration setting. The approved design keeps natural shares instead of adding sampling code. Camera types occupy 62.00% of routing.
- **A scene census after policy filtering:** that would erase excluded rows from the accounting. The independent census retains its pre-policy denominator and records policy deferrals separately.
- **Rewriting valid packed programs to hide a reader mismatch:** the reader uses the producer's authenticated chat-template boundary. `READER_METADATA_CHECK.json` records the boundary evidence.
- **Unrestricted direct-target rewriting:** S1-RD1 only converts an exact answer restatement to an empty thinking block and preserves the original text in provenance.
- **Synthetic images as proof of production data admission:** fixtures establish execution, not real RGB/mask integrity or accuracy. The job must admit the actual retained data.
- **Cold retries or cleanup:** a persistent run marker forbids an unverified parent restart. Failed states, source archives and fixtures remain available; no automatic deletion is allowed.
- **Importing the trainer before authentication:** this requires an ambient source path and can fail in production. The launcher uses a standard-library helper, and the worker installs only the authenticated source.
- **Login-node runtime staging as a launch proof:** it does not exercise the compute image and native local-disk layout. The authorized diagnostic uses the compute node and native bwrap paths.

## Risks and how to detect them

| Risk | Detection or decision |
|---|---|
| Natural routing shares overemphasize camera programs | Report per-type exposure and scores. The first-hour admitted-type report must identify missing or shifted source shares. |
| Some direct types have no language rows in the available reference | The mix table explicitly lists zero-coverage cells. Compare direct tasks with f17 at the registered boundary rather than assume coverage. |
| Metadata passes while actual RGB or masks fail | Native job admission verifies retained paths, a fixed hash sample, masks and independently expected scene removals before the first step. |
| Dataset-uniform FPS or lower-bound frame counts affect camera supervision | Keep the provenance flags; compare against stronger row/scene authorities when available. The pinned map has no capture timestamps. |
| Full-model memory or CUDA/FLA behavior differs from CPU | Run the real four-rank canary and require complete finite first-step verdicts. CPU results do not establish GPU fit. |
| A function-level dependency is missing or the sandbox path resolves differently | Require strict p/t/u preflight and the 47-module lazy-import list on the compute node before GO. Preserve module origins and tracebacks. |
| Save/export/transfer exceed disk or the one-hour reserve | The collective measured-byte guard reserves the whole leg. Time a real save, export, complete slot transfer and re-read. |
| The bundled change is mistaken for a component-level gain | Treat the run as one training candidate, not an ablation. Use matched comparators and keep call refusals in the denominator. |
| Parent initialization already saw dev-S1 scenes | Describe dev-S1 as a matched parent comparison, not clean held-out generalization. |
| Node-local source or evidence expires | Release requires a durable source-archive attestation. This lane does not authorize an archive transfer or deployment. |
