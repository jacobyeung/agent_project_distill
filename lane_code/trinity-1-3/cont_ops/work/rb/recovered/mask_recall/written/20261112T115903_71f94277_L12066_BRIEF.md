## Why
Our student answers metric spatial questions through short programs that fuse object masks with its geometry tower. On held-out development scenes, with the masks the deployed system produces (an open-vocabulary segmenter's candidates on 32 frames, filtered by a learned selector), programs beat direct answering only on absolute distance (46.9 against 38.9) and lose by 8 to 28 points on six other types; with ground-truth masks the same programs score 66 on absolute distance and 84 on counting. The route-table result names the largest single loss: objects the segmenter never proposes (about 28 points on absolute distance, 23 on counting). Mask proposal recall is now the lever that decides how much of the benchmark the program path can take. Nothing about it needs a GPU to analyse: the candidate cache and ground truth are on disk.
