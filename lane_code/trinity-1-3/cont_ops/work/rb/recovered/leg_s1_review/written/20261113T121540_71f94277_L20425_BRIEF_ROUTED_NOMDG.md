# Independent review: the routed reader for a checkpoint without an MDG head

## Context

A training leg (LEG-S1) teaches a student model to answer five question types by writing a measurement program: camera displacement, camera movement direction, camera rotation, absolute distance, room size. At step 100 and step 200 a rule called R1 is read: each routed type must score within five points of its **scripted program on the same runtime perception**, with a call rate of at least 95% and no version or call errors. The *routed read* executes the student's own emitted programs.

The leg has no MDG (mask grounding) head. The old reader (`/scratch/jjyeung/orch_cd/legs1_reads/out/routed.py`) refuses such a checkpoint: it admits only checkpoint-native MDG masks. A lane built a new reader under this ruling of the orchestrator: for a checkpoint without an MDG head, runtime perception is the geometry tower for pose and depth as before, and for object masks the external segmenter at the frozen proposal setting (`/scratch/jjyeung/orch_cd/official_reads/FUSION_PROPOSAL_SETTING_FROZEN_VSI_20261113.md`); the camera types and room size use no masks; a checkpoint with an MDG head keeps the old behaviour unchanged.
