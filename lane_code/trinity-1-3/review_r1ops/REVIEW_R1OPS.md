1. HIGH: chmod 0500 on KH/b will make proof 171356 FAIL. The proof (p_673bc60f.sh embedded source, decoded at review_r1ops/proof_decoded.py, lines 300-306) walks its whole work root and requires every directory to be 0700. Inside that root it runs job.sh's prefix, so p0.sh, then c.sh tk_stage, then tk_nx runs `rsync -rt "$HX/b" ... "$NX/"` (derived c.sh 398-401). Without -p, rsync creates NX/b, i.e. work/tmp/jjyeung/a_673bc60f/x_171356/b, at the source mode 0500. Proof 170956, which ran with b at 0700 and staged the same way, passed directory_modes (work/f170956.proof.json). Expect the receipt to read status FAIL, bad=[.../x_171356/b], with the loader audit still recorded. Classify this before the proof reports, so kill rule c does not misfire.
