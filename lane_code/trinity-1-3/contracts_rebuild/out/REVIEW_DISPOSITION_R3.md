## MEDIUM-3 — Head calls use the frames they name

Move horizontal components depend on the source frame; turn depends on both endpoint headings. Pose horizontal coordinates and yaw require the reference and queried headings. Depth's reference-frame horizontal coordinates require only the reference heading. Vertical coordinates and Euclidean move distance remain served. Calculators bypass these gates.

The tests reuse the reviewer's camera construction and gravity perturbations, including the later-frame nadir case. Served fields match the same perturbed geometry with availability checks disabled, or the direct gravity projection where the legacy vertical basis cannot exist. The source-frame distance test distinguishes the requested source from the reference camera. Source: [DECODE_ATTACK_R3.json](/scratch/jjyeung/orch_n30/contracts_rebuild/out/DECODE_ATTACK_R3.json).

Literal invariance of every field under changed gravity is not a valid requirement: changing gravity changes height and vertical displacement. Attack A preserves the printed horizontal move, turn, and distance while dy varies with the perturbation. The packet withholds heading-unstable fields and records the ordinary gravity-dependent variation rather than claiming unchanged vertical measurements. Source: [test_review_r3.py](/scratch/jjyeung/orch_n30/contracts_rebuild/work/tests_r3/test_review_r3.py).

## MEDIUM-4 — Admission and runtime share cache candidates

`candidate_phrases` constructs both sets. Cache-backed rows require `candidate_manifest`, `cache_phrases`, or the normalized candidate binding; a named ground without that binding defers with `contract_manifest_missing`. Materialization preserves the binding. `GroundV3` takes its universe from cache phrases when a cache exists, and `build_backend` propagates the supplied binding.

The regression loads admission and runtime manifests through separate file reads. A phrase absent from the cache defers at admission and hits the runtime's exact fixed-universe refusal. An extra cache phrase proves that the question parser cannot silently replace the cache. The POOL replay exercises native MDG parser membership; it does not claim that POOL supplies a real SAM cache.
