# Design record: contracts rebuild

The contract uses the reviewed gravity guard, a shared candidate identity, a per-row status audit and the marked MDG box bridge. One epoch boolean selects the contract throughout training, serving and replay. The model consumes RGB; tool numbers reach it as formatted text. Implementation and hashes: [PATCH_MANIFEST.json](/scratch/jjyeung/orch_n30/contracts_rebuild/out/PATCH_MANIFEST.json).

The guard and heading policy share the optical projection identity `||R[2,:2]||² = 1 − R[2,2]² = ||R[:2,2]||²`. Undefined heading withholds public coordinates and orientation while private original-world geometry supports metrics. The threshold is 0.3 in [geometry_profiles.py](/scratch/jjyeung/orch_n30/contracts_rebuild/work/src/student_pilot/geometry_profiles.py). A replacement heading basis would mix public coordinate conventions and is therefore excluded.

Candidate identity uses normalized full phrases. A supplied capture list defines candidate competition; absent a configured list, both admission and runtime parse question/options. An explicitly configured manifest remains mandatory for each named row. Terminal distance units are not part of an operand name. The real-row defect witness and complete agreement proof justify these narrow corrections: [REAL_ROW_DEFECT_B1.json](/scratch/jjyeung/orch_n30/contracts_rebuild/out/REAL_ROW_DEFECT_B1.json), [REAL_ROW_AUDIT.json](/scratch/jjyeung/orch_n30/contracts_rebuild/out/REAL_ROW_AUDIT.json), [REAL_CANDIDATE_UNIVERSE.json](/scratch/jjyeung/orch_n30/contracts_rebuild/out/REAL_CANDIDATE_UNIVERSE.json).

A failed ground permits one different listed ground, then a direct answer. Calls after that retry, repeated names, operator faults and unrecognized responses defer the row. The supplied ruling defines this behavior: [trace ruling](/data2/jjyeung/agent_project_data/distill_design/TRACE_RULING_20261115.md:276). Unknown templates can still require explicit candidate phrases; deferrals expose that missing binding.

The MDG bridge aliases already-cut points only when the marker declares the cut. Recutting would change the geometry. OFF replay preserves sealed behavior; ON intentionally repairs unavailable boxes and withholds undefined headings. Exact metric comparisons and explicit unavailable-output exceptions appear in [CPU_PROOF_B2.json](/scratch/jjyeung/orch_n30/contracts_rebuild/out/CPU_PROOF_B2.json).

Integration preserves the tree event-row branch and the contract heading branch. The edits commute byte-for-byte; only the geometry patch needs a hash-bound rebase. Application stages and verifies the full tree before installation.
