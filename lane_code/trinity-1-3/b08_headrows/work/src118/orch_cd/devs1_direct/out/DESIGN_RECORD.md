`resolve_labels.py` can create a new frozen payload from a complete, source-pinned supplement under the current two-label ruling. It refuses replacements of existing labels and incomplete supplements. The operator must review source semantics and units. A different missing-label policy requires an explicit ruling and an adapter change before inference.
