Run this kit only in a separately admitted production measurement allocation. It has not run on a GPU.

Set `TREE`, `CONFIG`, `OUT` (fresh scratch path), `PYTHON` (production venv), and optionally `RESUME_PIN` (an explicit checkpoint pin). Apply the production overlay before `bash probe.sh`. Run `bash run.sh` on the allocated four-H100 host. The launcher retains the trainer's admission, model initialization, FSDP wrapping and checkpoint restore. It substitutes a disposable measurement loop for checkpoint/export/evaluation scheduling. It never publishes a model.

The hard budget is 900 seconds including startup and termination grace. The loop performs one warmup optimizer step and one instrumented step. Cold startup can use the budget before completion; exit 124 is incomplete and must not trigger an automatic retry. A warm, explicitly authorized checkpoint run is preferable. One warmup does not establish steady-state kernel compilation: run A takes about 20 steps to settle. Label this a phase profile, not a steady-state throughput measurement.

Each rank emits `phase_table.json` and a printed table with phase name, call count, host seconds and CUDA-stream elapsed seconds. Ranges cover data/admission, copies, forward, backward, decoder recomputation, both vision towers, heads, FSDP unshard/reduce, gradient norms/clipping, optimizer, scalar metrics and explicit synchronization. `steps.json` retains the real trainer's wall/data times and peaks. CUDA events add no per-range synchronize; only table collection synchronizes.

The detailed `trace.json` and `profiler_table.json` cover a bounded prefix (four microsteps by default), avoiding a whole-step trace with millions of fallback events. CUDA-event ranges cover all 72 microsteps and the optimizer tail. The prefix is pose-heavy; it cannot alone estimate VQA/routing/pointing kernel mixtures. Inspect the full-step phase table for those totals. Module and FSDP ranges are nested: do not add inclusive range times. CUDA-stream elapsed time includes stream waits and CPU launch gaps; it is not pure kernel execution time. CPU `float`/`.item()` synchronization appears under `_local_scalar_dense`/synchronize in the trace; allocator queries are separate and are not presumed to synchronize.

Open `trace.json` with a local Chrome-trace viewer. The NCCL interval union and its overlap with compute distinguish communication time from exposed communication. `trace_summary.py` prints kernel union time, NCCL union time, compute union time, NCCL-only time and device gaps. NCCL-only time is an upper-bound proxy for exposed communication, not a critical-path proof: kernels can wait for ranks or share resources. Full-step FSDP stream ranges complement the short trace. Never sum rank totals for a step's latency; use the slowest rank.

The probe must print CUDA availability, accepted package gates, source paths and individual callable bindings. `fast_path=False` alone cannot tell whether FLA is running. `launch.py` also records actual instantiated DeltaNet bindings and dimensions in its manifest.

`disposable.py` adapts exactly two native `train` statements in memory: it permits an explicit checkpoint with the bounded smoke loop, and it redirects training receipts and locks into `OUT/trainer/smoke/<attempt>`. It refuses a changed source pattern. Native configuration validation, source authentication, allocation checks, checkpoint restoration, model initialization and FSDP wrapping remain active. The configuration stays unchanged; gate history and checkpoint inputs are read from their authenticated original locations. No measurement receipt is written into the production run directory. Each timing arm has its own fresh receipt directory.

The kit uses the installed torch 2.11 profiler APIs (`torch/profiler/profiler.py:285,347,601`, `torch/cuda/streams.py:159–245`) and [the versioned profiler documentation](https://docs.pytorch.org/docs/2.11/profiler.html). Source instrumentation wraps the imported function in memory; it does not edit the reviewed trainer. CPU tests validate the instrumentation, but GPU execution remains untested.
