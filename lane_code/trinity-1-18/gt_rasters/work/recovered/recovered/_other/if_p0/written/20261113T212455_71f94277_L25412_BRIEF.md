# Lane if_p0: build the kit for experiment IF-P0 (vision-only branches in the early LM layers, read by the pose probe)

## Why

The user pointed us to "Unbundling Multimodal Vision Encoding" (arXiv 2611.17334): parameters that only vision tokens use can sit inside the first eight layers of the language backbone ("in-fusion": zero-initialized vision-only attention deltas and an FFN branch) and match a separate vision encoder. Our student encodes each video frame alone and its vision tokens probe at chance for relative camera pose; the language model's layers are the first place where frames meet. The hypothesis to test: zero-initialized vision-only branches in LM layers 1 to 8 let a frozen student compute cross-frame pose that the per-frame encoder cannot give. The user's rule is that every candidate experiment's code and kit are built and debugged before a GPU frees up; this lane builds that kit. It runs nothing on a GPU.
