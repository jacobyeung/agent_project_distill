# trace_save (Devin): archive the session records of our own Devin coding lanes for audit and cost accounting, and report the tokens each lane spent
Purpose and scope: the user runs coding agents (Devin lanes) on their own research project and wants each lane's session record kept (messages, tool calls and the step-by-step reasoning text that Devin itself records, which the user calls "thoughts") so they can audit what the agents did and see where tokens are spent. The records are the user's own logs, stay on the user's storage, and are not used to train any model.
