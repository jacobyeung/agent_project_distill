# Admission argument — PARTIAL; no native adopter is delivered

**This package cannot cause a GPU job to train on a cross-run store: it adds no GPU-wrapper adoption path.** Existing preparation and admission remain active. The CPU entry calls the existing native `admit(..., prepare_only=True)` and emits a path-bound journal, not a portable root. The experimental store API verifies bytes only. It never generates `request.json`, a source seal, or `data_receipt.json`, and it never publishes into a training destination.

The stronger claim requested for a useful adopter—prepared data equals what this job's own preparation would produce—is **not proved**. The following table distinguishes tested primitive checks from missing admission checks.

| Difference path | Check and evidence |
|---|---|
| Corrupted or purged object; partial root | Full SHA/size verification refuses. `test_corrupted_prepared_object_refuses`, `test_missing_object_refuses`, `test_partial_root_refuses`. No GPU fallback/loss comparison was run. |
| Incomplete publication or dangling reference | The publisher verifies the complete declared graph before root rename. `test_incomplete_graph_cannot_publish_root`, `test_missing_payload_cannot_publish_root`, `test_interrupted_root_rename_does_not_publish`. |
| Foreign input key | Explicit expected-key equality refuses. `test_foreign_key_refuses`. The expected key is supplied by the caller; a native planning pass to derive it is **missing**. |
| Changed consumed configuration, file byte, environment or source | Recorder replay refuses changed/new accesses; source-byte changes change its key. `test_consumed_field_change_refuses_replay`, `test_file_byte_change_and_undeclared_file_refuse`, `test_declared_environment_change_and_unknown_environment_refuse`, `test_source_file_change_changes_key`. Integration with all native readers is **missing**. |
| Hidden dependency or new native read | `test_injected_unkeyed_config_read_is_refused` and `test_raw_python_file_read_is_refused` cover the explicit recorder/Python guard. C-extension reads, captured references, direct environment access and filesystem metadata are **not comprehensively intercepted**. This guard must never serve as a production admission boundary. |
| Run-dependent content | The recorder refuses excluded fields; the actual native identity function triggers that refusal. `test_actual_native_identity_refuses_excluded_reads_under_recorder`. Native output/config/source-seal separation and portable SQLite serialization are **missing**. `test_native_frame_audit_contains_physical_paths_and_differs_between_dirs` exhibits the problem. |
| Path escape, link or shared writable store | Names and store ownership/mode are checked; object opens refuse links. `test_duplicate_and_traversal_names_refuse`, `test_object_symlink_refuses`, `test_linked_store_directory_refuses`, `test_shared_writable_store_refuses`. Malicious same-user concurrent mutation is outside this primitive's trust model. |
| Object changes during materialization | Copying rehashes every object. `test_materialization_rehashes_bytes_after_verify`. The private directory never becomes a native admission destination. A native atomic adopt/rollback protocol is **missing**. |
| Old/foreign native journal displaced on a miss | The store never replaces an existing destination. `test_materialization_preserves_existing_native_destination`. The CPU runner preserves native refusal and partial journals (`test_cpu_entry_keeps_native_failure_and_partial_journal`). GPU miss receipts and full fallback integration are **missing**. |
| Self-consistent forged output under the right key | **Hashes and key equality do not prevent this.** `test_hashes_alone_are_not_producer_authentication` builds two valid roots with different payloads and the same key. A production design needs a separately trusted producer/root binding and a reviewed deterministic native transformation, or recomputation of the output. |
| Nondeterministic output, wrong rows, RNG or first loss | The comparator rejects any declared object difference (`test_determinism_compares_every_entry_without_normalization`). Native two-node cold builds and every-rank bitwise loss comparisons, including all fallback twins, are **missing**. Fixture equality does not discharge these obligations. |
| Stale source/config admission copied from another run | No admission is copied or synthesized. A native regeneration path authenticated against the new run is **missing**; enabling adoption before it exists is unsupported. |

**Review disposition: keep adoption absent.** The tested primitives and CPU entry are reviewable groundwork. They do not support a GO for cross-run reuse, a claim of minutes saved, or preparation of an N handover before its selected export exists.
