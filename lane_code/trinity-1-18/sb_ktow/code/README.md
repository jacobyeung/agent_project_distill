The tower-frames kit runs G3T and SAM 3 with 32 or 64 views while retaining the language model's 32 anchors. `scripts/cpu.sh code/dryrun.py` exercises stored K1 captures. `scripts/cpu.sh code/test_kit.py` runs the regression checks. `scripts/cpu.sh code/evaluate.py A`, `B --split train`, `B --split heldout`, and `C` price completed captures.

`configs/KBOX_WINNING_BOX_RULE.json` is the single deferred box-rule hook. A passing binding supplies `decision_path`, its `decision_sha256`, a slash-separated `pass_pointer` resolving to `PASS`, and a pinned `module_path`, `module_sha256`, and `callable`. The callable is a factory receiving `{capture, cache, geometry, n_frames}` and returning `lift(name, selected_masks, geometry)`. The factory has the raw-name proposal cache and can apply kbox's exact winning gather/fusion rule. An absent or failing winner omits `F64_fused`.

The camera pass requires a staged `inputs/CAMERA_ITEMS.json` from the named `san_kit.routed(544, types=[...])` producer. No such file is fabricated. Its contract is `{source, step:544, sources:[{path,sha256}], captures, items}`. `source` names the module path in the specification. Captures use the K1 capture fields needed for tower calls: canonical ID, dense_frames with index/path/sha256, anchor_slots, and anchor_indices. Each item carries its authoritative id, capture, room, type, call, stored_response, raw_pose32, depth32, scale, gravity, anchor_slots, truth, options, and frame_gap. The producer must establish all joins; do not infer them from export filenames. `depth32` must be the stored G3T anchor grid, not own depth. Existing mask-only exports cannot satisfy this contract.

The baseline camera formatter executes the unchanged reader `OwnGeometry` definitions extracted from `carrier_c1_routing.py`. The exact named `pose_k1.py` is copied unchanged under inputs. G3T runs through `FrozenG3TTower.run`; its optional all_depth path samples every dense slot after the same aggregator pass. SAM 3 runs through `Sam3Tower.encode` and `e2e_reader.stage1.sam3_detect`, with raw names, joint floor 0.05, cap 30, 1008 pixels, and bf16. Anchor-cache replay discards alias prompts and restores each raw prompt's source presence before filtering.

Dense-frame IDs remain internal. The box uses its dense-frame points; its printed frame list includes only actual shared anchors, renumbered by the manifest's anchor_slots. The printed best frame is the largest observed shared anchor. An object without any shared anchor refuses instead of inventing an anchor membership. `F64_flagged` selects each operand's dense box only when the F32 printed response contains fewer than three frames.

Selector features and learned weights stay unchanged, including their existing 32-frame feature denominators. Top-1 diagnostics apply the K1 label rule (IoU > 0.5 on at least half of labelled member masks) to the 32 authoritative GT anchors for both tower counts. Full 64-frame labels are MISSING because the supplied GT rasters contain only 32 frames. The code reports that limitation beside the anchor-only diagnostic.

Pose bootstrap uses 5,000 paired capture draws. Distance and camera bootstrap use 10,000 paired room draws, preserving item weights. Every bootstrap uses seed 20261119. The 10,000-draw room setting is inherited from the box-ladder specification because the tower specification does not give a separate count. B held-out pricing requires `configs/CODE_REVIEW.json` with status APPROVED and code_sha256 matching the code identity receipt; it allows one completed look. Missing outcomes never satisfy a bar.

Future launch scripts require a separate workspace `inbox/GPU_GO.json` with status GO, permitted parts, and code_sha256. The DA3 backend also requires a standalone GO line in `inbox/DA3_GO.txt`, as its own validator requires. `configs/K1_PEAK_MEMORY.json` must contain a verified measured peak, its log path, and its log SHA-256. Current files deliberately block launch. No GPU permission is implied by this kit build.

Part limits are 1 hour for A, 4 for B, and 1 for C, with a shared six-hour wall-clock deadline from the first GPU start. The outer timeout also covers preflight and model imports. Resume accepts only matching input/code bindings and hashed outputs. Partial attempts and HALTED runs require operator review; no job is relaunched automatically. Part C always retains DA3 arms after an A stop; only its G64 arm is gated by A.

The tar contains source code, configs, launch scripts, specification copies and review receipts. It contains no frame data, manifests, model weights, masks, or tensor caches. To use the archive elsewhere, stage the exact manifest with its recorded hash into inputs and bind the specified local data paths. Transport is left to the orchestrator; this build makes no network connections.
