## 4. Programs (CPU; the reader's `StageOne` with rule `candidates_argmax`, then the box rule; a `not seen` or `box unavailable` operand makes the program refuse the item)
Box rules: `today` = `lift_bestspread`; `obj` = kit 1's frozen object variant, if bar `replace_box` passed both of its parts (kit 1 on the stored geometry, kit `tower_frames` Part A at 32 input frames). On R0-dev each category runs one form, the fallback form: a refused item keeps the present path's answer, as a routed model answers directly after a refused call. The strict form (a refused item scores 0) runs on dev-S1 only.
- **Absolute distance (290):** two grounds and `box_grid_5cm`, as the reader prints it; metres. The present call (linker, selector, `today`, 32 frames) and the frozen arm are computed from the same proposals and geometry; a refusal of the frozen arm keeps the present call's answer, and an item both refuse scores 0 in both.
- **Size (293):** the longest edge of the printed box, in centimetres.
- **Relative distance (279), two-candidate check:** parse the direct trace's stated order with `r0rel.py`'s pattern ("the nearest-to-farthest order from the X is: A, then B, then C, then D"); take the two candidates it places nearest the asked end; compute the box gap from the reference object to each; answer the one the gaps favour; if any of the three grounds refuses or the trace states no order, keep the direct answer.
- **Appearance order (246):** the first printed frame of each named object from the frozen source; the option whose order equals the order of those frames. Two objects with the same first frame leave their pair open: if exactly one option agrees with every other pair, answer it. If an object is not seen, the pairs leave more than one option, or no option matches, keep the direct answer.

## 6. Scoring and statistics
- **Scorer (reproduces the stored direct `score` on 678 of 678 R0-dev and 300 of 300 dev-S1 numeric rows):** numeric types score `mean over c in numpy.linspace(0.5, 0.95, 10) of [abs(pred - truth) / truth <= 1 - c]` in float64, with `truth` = the row's `gt_released` (equal to `gt` on R0-dev; for absolute distance the item's `answer`); choice types score 1 when the answered letter equals `gt`.
- Paired differences on the same items; 95% percentile bootstrap over rooms (scenes), 10,000 draws, seed 20261119; item-weighted means decide the bars.
- **Benchmark points (reported beside type points):** ReVSI is the mean of seven categories, each the equal mean of its subtypes: size / 7; relative distance = mean(closest, farthest) / 7; absolute distance / 7; ReVSI has no appearance-order category. VSI-Bench divides a type's points by 8.
