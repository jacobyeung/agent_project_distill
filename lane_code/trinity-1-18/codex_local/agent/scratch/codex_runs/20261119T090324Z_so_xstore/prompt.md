Prepare-only entry (switch default OFF): runs the SAME native preparation code (not a reimplementation) without GPU and writes a content-addressed, run-path-free store: objects under their sha256, canonical receipts without absolute paths, host names, UUIDs or timestamps (those go in separate telemetry), and a root manifest naming the full object graph and the key; atomic publication (temp then rename), an incomplete store never becomes a root.
