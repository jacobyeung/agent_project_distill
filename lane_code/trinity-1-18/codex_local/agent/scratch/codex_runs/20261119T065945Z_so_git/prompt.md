## Facts
- Rules: lanes run no git; one owner serialises; never in the /home working tree; never rewrite history; never push to main; never force.
- The owner today is the hourly loop on trinity-3-30 (`while true; do bash .../orch_n30/tools/lane_code_sync.sh >> /scratch/jjyeung/distill_sync/sync.log; sleep 3600; done`). It holds `flock -n` on `$S/.sync.lock` (`S=/scratch/jjyeung/distill_sync`), stages whitelisted files of `/scratch/jjyeung/orch_n30/*/` from trinity-1-18 (IB tar stream) and trinity-3-30 plus `orch_n30/tools` and `orch_n30/briefs`, secret-scans them, copies into the clone `$S/repo/lane_code/<node>/...`, commits on branch `lane-code` and pushes to `origin` (GitHub) and `home` (the /home repo as branch lane-code), verifying with ls-remote. A failed run writes a BLOCKER event into `.../orch_n30/events/code_sync/`.
- The real clone lives only on trinity-3-30. Here you build and test against a throwaway setup you create under `$L/work/` (a bare repo standing for origin, another for home, a clone on branch lane-code, a fake stage), using the `LCS_*` test variables the sync script already honours where useful.
