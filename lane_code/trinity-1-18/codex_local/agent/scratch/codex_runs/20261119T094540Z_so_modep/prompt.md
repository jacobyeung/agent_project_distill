## Why
Every training launch spends 140.57 min (job 172660) / 145.27 min (job 171377) in mode p while four H100 idle. A cross-run store (moving mode p out of the allocation) needs native identity changes (the native identity consumes `output`/`preparation_output`, frame inventories embed physical paths, full preparation needs the selected parent export): see `/scratch/jjyeung/orch_n30/so_xstore/out/REPORT.md` and `INPUT_AUDIT.md`. This task instead makes mode p itself faster inside the same allocation, same node, same job, with outputs identical to today's.
