## Question

1. Which events write a checkpoint and which write an export (step 1, every 7,200 s, local steps 100/200/400/600/800/1000, the self-stop, a TERM at 600 s before the wall, a USR1), and what name, step label and manifest each gets.
2. Can two objects get the same name, or a stop object be labelled with the wrong step (for example a checkpoint finishing after the nominal self-stop, or an ordinary checkpoint already uploaded before the stop)?

4. Does the restarted leg's step counter, schedule position and sampler position continue from the stop, and where is that recorded?
5. The time budget: planning reserves 600 s per checkpoint and per export while writes measure 56-77 s; does that reserve leave GPUs idle, or is it overlapped with upload?
