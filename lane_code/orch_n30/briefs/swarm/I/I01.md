## Method
1. For each benchmark and question type, write down how the official code scores it: answer extraction (for example a first-token fuzzy match that strips a trailing period), multiple-choice matching, numeric scoring (mean relative accuracy over thresholds 0.50 to 0.95 in steps of 0.05, or whatever the code says), handling of non-numeric or empty answers, and aggregation (mean over items, over types, how direction subsets combine, overall as mean of types or of items). Cite file:line in the vendored copy. Do the same for each of our scorers.
2. Vendor the official functions verbatim (with their license header and source line) into S/work/I01/official_vendored/ and build a harness that scores one (type, truth, prediction) triple with both.
3. Synthetic cases (no item text): per type, truths and predictions covering integers, decimals, comma decimals, thousands separators, leading or trailing words, units (m, cm, mm, ft, feet, inches, meters, square meters, m², sq ft), scientific notation, negatives, zero truth, ranges ("3-4"), fractions, number words, option letters ("B", "B.", "(B)", "b", "Option B", "B) chair", the option text alone, two letters), answer tags and thinking blocks, very long outputs, unicode digits, empty, whitespace and None; plus aggregation cases (empty types, ties, unequal type sizes). Write them to R/files/I01/CASES.jsonl.
4. Run both scorers on every case; group divergences into classes (R/files/I01/DIVERGENCES.md: class, minimal example, official output, ours, file:line on both sides).
5. Price each class: re-score every scored arm answer in the development reads with the official scorer, count disagreements with the recorded score by type and read, and convert to points per 100 items of that type and to benchmark points through the type shares. A class that never occurs in our outputs is LATENT (reported with its case, unpriced).
6. Where our scorer is wrong, deliver a patch (unified diff against the staged file) that matches the official behaviour behind a flag that defaults OFF, with a test showing flag OFF leaves every recorded score unchanged.

## What counts as a finding
