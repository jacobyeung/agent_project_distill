## Goal and why
The project builds a ~9B spatial VLM that answers from RGB and calls heads inside its own checkpoint in its chain of thought. The teacher collector's supervisor hard-codes the package path to the live working tree, so the repository's own provenance rule (launch only from an immutable epoch checkout under /home/jjyeung/agent_project_distill_epochs/<commit>) cannot be followed; this patch removes that blocker before the next epoch.
