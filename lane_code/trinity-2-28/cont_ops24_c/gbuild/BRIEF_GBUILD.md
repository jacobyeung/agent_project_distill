## Part C: point-prompt mode for a closed-model ceiling (design + implement if feasible)
A closed model will return, per (item, object name, anchor source index), either "absent" or one point. Add a worker mode (`--points FILE`, schema `{item_id: {object_name: {source_index: [x_norm, y_norm] | null}}}`, coordinates in [0,1] of the anchor frame) that, for each called object, replaces text detection: absent frames give no mask; a point drives SAM 3's `forward_grounding` with a geometric point prompt (see `stage1.sam3_detect`, which passes `_get_dummy_prompt()`; find the prompt class in `tree/student_pilot/sam3_tower.py` and the payload) together with the text, keeping the mask that contains the point with the highest joint score; the frames form one track; the selector is skipped; lift and gap run unchanged; responses are recorded like the ground/gap calls so the same scorer applies. If the SAM 3 source needed for geometric prompts is not in the payload, write exactly which symbol is missing and keep the mode as a stub that refuses.
