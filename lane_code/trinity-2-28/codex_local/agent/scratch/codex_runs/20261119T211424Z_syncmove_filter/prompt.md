# syncmove_filter: stop the hourly lane-code sync from committing build by-products (gpt-6-astra)

Workspace `L=/scratch/jjyeung/orch_n30/sm_filter` (yours to write).

## Context
An hourly job stages agent-written files from `/scratch/jjyeung/orch_n30/` on three nodes (labels trinity-1-18, trinity-2-28, trinity-3-30) plus two small dirs (labels orch_n30/tools, orch_n30/briefs), secret-scans them, copies them into a Git clone under `lane_code/<label>/...`, commits and pushes branch lane-code. What gets staged is decided only by `in/tools/lane_code_filter.py`: it runs with cwd = the tree root, walks it, prunes directories by `DIRRE` (matched against the directory basename), `SUBSTR` (substring of the `/`-prefixed relative path), `MAXDIR`, keeps files by extension and size, deduplicates by content, and writes the duplicate manifest `code_sync/meta/DEDUP_<label>.tsv.gz`. Production runs the `robust_scan()` path (env `LCS_ROBUST_SYNC=1`); the legacy loop below it must get the same rules. The filter is sent to each node as a heredoc on stdin (`python3 -I -s -B - <label> <manifest>` with delimiter `LCS_FILTER_EOF`), so it must stay one self-contained stdlib file and must not contain the strings `LCS_FILTER_EOF` or `PYEOF`. `in/tools/dry_count.py` reads `MAXDIR`, `SUBSTR` and `DIRRE` from the filter by AST; keep it consistent with whatever you add.

The clone grows by 45-230 MB of raw file content per hourly commit. `in/commits/sm_<commit>_s.txt.gz` lists, for each of the last 8 hourly commits, every added or modified file as `<size bytes> <blob sha> lane_code/<label>/<path>`. Most bytes are build by-products: test-run output trees (`*/test_runs/*`, `test-artifacts/<32-hex>/...`, `LANE_TEST_OUTPUT`, `B2_TEST_OUTPUT`, `TMPDIR`, `R2_PROOFS`), Python tempfile directories (`finetune_gate_test_typ_3nah`, `provisional_zl3iszux`, `driver_a2sjw8b2`, `sam_r10_ljgx_vjf`, `direction_prior_<32-hex>`, `fix3_b_arms_<32-hex>`), staged payload copies with vendored interpreters (`payload/environment/lib/python3.12/...`, `conda-meta`), extracted archives (`work/extract/...`), nested copies of other lanes' trees (`fb_pack/ro/orch_n30/...`, `payload/files/scratch/jjyeung/...`, `so_in/scratch/jjyeung/orch_n30/...`), build rehearsals and attics (`work/build24f/rehearsal3/...`, `w24/attic/...`), `*/work/build*/work/*`, `patch_validation_*`, `fixtry`, sandboxes, and caches. Also, the DEDUP manifest (8-11 MB for trinity-1-18) is committed as a new blob every hour even when its content is unchanged, because gzip stores the current time in its header.
