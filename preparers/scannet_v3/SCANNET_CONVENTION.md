The ScanNet v3 preparer authenticates the RGB receipt against its caller-supplied digest and the contract-pinned PLAN before reading corpus sources. Its CONTRACT.json covers every other file in this full package copy; callers pin the contract digest separately. The contract authorizes CPU materialization validation only. It is not a collector contract, and the adapter writes no registry.

The adapter reads SensorData v4 little-endian streams, JPEG color and zlib-compressed uint16 depth. It preserves both 4x4 intrinsics, both extrinsics, depth shift, dimensions, frame record offsets, source ordinals, source camera-to-world poses, timestamps, and compressed color/depth payload hashes. It verifies the entire source stream hash before and after preparation. The released depth values are in metres after division by depth shift; geometry observations use the unchanged mesh renderer, not sensor depth. Sensor timestamps can be zero and are recorded as such; VSI timestamps remain ordinal/video-fps and are never asserted to equal sensor timestamps.

Only streams with exactly identity color and depth extrinsics are supported. ScanNet's official calibration tool identifies these as already color/depth aligned. Header intrinsics remain authoritative even when the text metadata contains different values. Nonidentity extrinsics are refused; the adapter never estimates a transform or reapplies the metadata color-to-depth extrinsic.

Mesh vertices and selected sensor camera-to-world poses retain the released raw world frame and metric scale. The sensor-to-mesh transform is identity. The metadata axisAlignment matrix is preserved but applied to neither mesh nor poses. The teacher's `aligned_pose` field aliases `identity @ sens.camera_to_world` for finite poses. A non-finite pose uses the nearest finite neighbor within five raw frames on each side: translation is linear in frame index, rotation uses shortest-path slerp, and a single available neighbor is copied. Every neighbor and resulting pose must pass the unchanged proper-rigid check; a finite improper pose or an absent finite neighbor causes refusal. `interpolated_pose_slots` identifies every derived pose; non-finite entries in its recorded raw matrix are JSON null, and the pinned sensor bytes retain the original values. No released `aligned_pose` JSON field is asserted. The inherited `geometry_source` string identifies the unchanged geometry interface; this source receipt supplies its exact corpus-specific meaning. Canonical teacher coordinates come from the unchanged joint point/pose transformation with gravity +Z and scale 1.

Every selected PNG must byte-match decoding its VSI video ordinal. All 32 source ordinals must exist in a stream with the same frame count as VSI. The decoded sensor RGB is resized with OpenCV INTER_AREA to the VSI canvas. The Pearson correlation over all BGR values must be finite and at least 0.99 at every slot, exactly as in the ScanNet++ path. Only a same-ordinal correlation shortfall triggers a bounded raw offset search from -3 through +3. The highest finite correlation must reach 0.99; ties retain the first maximum in ascending offset order. `correlation_offset_slots` binds the selected raw record and its pose to the unchanged VSI ordinal and records the before/after correlations. Neither selected RGB, crop, threshold nor calibration is substituted. The target intrinsic is diag(VSI_width/source_width, VSI_height/source_height, 1) times the header color intrinsic. All raw sources, video, PNGs and selected-index assets are hash-bound.

The annotation mesh is `<scene>_vh_clean_2.ply`, the segmentation is `<scene>_vh_clean_2.0.010000.segs.json`, and the aggregation is `<scene>.aggregation.json`. A separate carrier preserves the object ID for every vertex and the original segment ID. Labels and object IDs remain exactly those of the aggregation. A face belongs to an object only when all three vertices belong to it; mixed and unannotated faces receive -1. All source vertices and faces remain in scene geometry. Duplicate membership, missing segments, duplicate IDs, degenerate boxes and instances without any complete member face cause refusal. The last restriction prevents the unchanged donor's box fallback from presenting derived box surfaces as annotated object surfaces.

Boxes follow `source_derived_raw_world_AABB_all_member_vertices_center_midrange_half_extents_v1`: for every official object, take every associated vertex, including vertices excluded from mixed faces; compute componentwise minimum and maximum in raw metric world coordinates; set centroid=(min+max)/2, axesLengths=(max-min)/2 and normalizedAxes=identity. Do not pad, fit PCA, rotate into metadata axes or substitute label priors. These are deterministic source-derived axis-aligned estimates, **not released box annotations**. The instance carrier, provenance, scene receipt instance pin, input receipt and success/refusal receipt all declare `released_boxes=false`, `obb_estimator_used=true`, the exact box convention, and `provider_axesLengths=half_extents`. Admission enforces these declarations without extending the collector receipt field census. The teacher consumes half-extents through its unchanged OBB interface. Box orientation therefore describes raw world axes and must not be interpreted as an estimated object's physical orientation.

The unchanged renderer must provide valid support and <=0.05-pixel lift/reprojection residual in all 32 frames. The unchanged grounding renderer must find an officially associated instance with >=32 visible mask pixels in every frame. Candidates are sorted by face count then ID; the adapter uses full deterministic search without rejecting boxes that cross the near plane. It records every chosen instance, checks the unchanged matcher/boxes/points interfaces, and saves visual proofs at slots 1 and 17. The donor retains its 30,000-face per-instance sampling, near-plane triangle handling, vertex-splat scene depth and 0.15-metre occlusion tolerance. A lift/reprojection check verifies camera consistency but does not independently prove mesh registration against RGB or sensor depth.
