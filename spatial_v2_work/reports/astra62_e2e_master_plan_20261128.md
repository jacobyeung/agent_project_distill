# Spatial-V2 | One checkpoint for spatial QA, manipulation and navigation | 28 Nov 2026

**Decision: build on Arm C. Do not ship the current Stage-2 launcher as Arm C.** Preserve C's pretrained camera decoder, distill metric scale and foreground masks into native heads, and let both language and actions read the same soft 3D object representation. The decisive test is not whether the model predicts depth: it is whether changing the **base checkpoint alone** improves five-demo LIBERO, unseen camera views **and** unseen navigation episodes.

## Evidence that changes the build

- On the same 53 held-out captures, C at **step 0** scores 9.964° rotation, 86.37% below 15°, 11.662° translation direction and 91.60% depth δ1; at **step 2**: 9.957°, 86.38%, 11.658°, 91.60%. Rotation is the **mean of per-clip pair medians** (step-2 median across clips: 6.40°). This is inherited geometry, not two-step learning. B at 2k: 45.05° and 21.45%; its 52/53 wins over A are **depth** wins. Keep B's gravity target (4.78° vs C's 9.45°); B's ScanNet 0.084 AbsRel/94.1% δ1 is an eight-capture slice at step 1,750, not an overall target.
- Habitat, 100 frames in 20 episodes at 90°: `vc_raw` depth ratio/AbsRel/δ1 = 1.760/.891/14.4%; `da3_raw` = 1.268/.391/43.0%; `da3_fovfix` = **.969/.100/90.4%, 5.5 cm leg error**. The last two isolate the focal correction. These are depth and oracle-click leg diagnostics, **not policy success**. C's own step-2 FoV error is 25.84%: accept calibrated intrinsics when available.
- DA3 cut ARKit gross pose failures (>15° max) from 10/14 to 3/14 on dev-S1. Self-depth TT-BA **worsened** K1 max rotation by 0.48°. `reproj_p90` (AUROC .898 for >30° failure, 2.98 ms in the diagnostic) ranks suspect geometry; it does not repair it. The reported 0.42% ScaleAnchor error is a calibration result, not a guaranteed scene-scale error.
- J1-T on 117 items: dropping <1%-area targets costs 18.12 MRA points against the box oracle; admitting empty-frame detections costs 15.30; filling boxes instead of segmenting costs 9.06. Box IoU .50 breaks; .70 is a **pilot floor**, not parity. E05's .9585 is **agreement between two models** on 98 accepted boxes (.8558 against projected GT), not micro-object mask accuracy.

## The deployable graph (specification, not a claim that it already runs)

1. **Contract:** `SpatialV2.forward(RGB, timestamps, view_ids, valid, text, K?, proprio?, state?) → logits, geometry, action_distribution, state′`. All learned weights, camera conventions and normalization constants belong to one model bundle. No GT depth, GT camera trajectory, GT masks, object IDs, simulator state, saved scene features, teacher imports/services or XML execution. Known sensor calibration and measured proprioception are legal inputs, declared identically for both policies. Only the environment's final sampling/actuation lies outside autograd.
2. **Two visual paths, one module.** Native Qwen visual encoder preserves semantics. C's ViT-G/14 has 40 blocks, width 1536, alternating local/global attention from block 13, local+global output width 3072 and camera tokens; load its CameraDec, relative DualDPT and calibrated RoPE convention. For matched 16-view geometry use 280² C / 320² Qwen → aligned 20² patches → 10² merged tokens per view. Share the crop transform, not a guessed token ordering. Preserve fine features before merging.
3. **Native depth and intrinsics.** DualDPT predicts relative optical-axis depth `z_rel` and confidence. A trainable log-depth head predicts metric depth `z0` at predicted focal (centered shape + per-view shift + shared clip log-scale); distill the Nested metric branch into it in 1B. **Do not export that second metric ViT.** Predict `log(|fx|/W), log(|fy|/H)` and principal point; use full resized/cropped `K` where known. Set `zK = z0·(|fx|/W)/(|fx_pred|/W)` **once** on the same raster; otherwise `zK=z0`. Carry focal sign separately in ray construction. Condition on both focal axes; test anisotropic resize by unprojection parity, not a second multiplier.
4. **Pose, gravity, scale.** Compose zero-init residual `exp(δξ)` with CameraDec's relative SE(3). Fit positive shared translation scale in fp32 by confidence-weighted least squares `s_cam=Σw z_rel zK/(Σw z_rel²+ε)`. Predict normalized per-view gravity, rotate into view-0, soft-pool and level to +Z-up. Where observable, apply **one common residual scale** to `zK` and camera centers, from measured FK baseline or known camera height / predicted floor height. Weight log-scale continuously by baseline, floor support and residual; absent evidence → identity with high uncertainty. No per-frame GT fit, hard floor RANSAC, assumed human height or second focal correction. Relative-only clips get no absolute-scale loss.
5. **Object and motion interface.** In fp32 lift `P_world=Rᵀ(z K⁻¹[u,v,1]−t)` for world→camera `(R,t)`. Use 32 soft queries: 1 camera/scale + 31 entity/region slots. Text embeddings and pre-merge RGB features predict per-view presence, soft box center/extent and foreground weights. Bilinear `grid_sample` on native-resolution features from a shallow shared RGB stem yields 28² masklets; include a fixed full-frame multiscale grid so a missed coarse box can recover. No argmax crop, thresholded mask, detached XYZ or teacher box at test time. Fuse via uncertainty-weighted cross-attention over visible samples; handle occlusion separately from evidence of empty space.
6. Each entity carries appearance, 3D center/extent, visibility, covariance, rigidity and world displacement at offsets `{-1,+1,+4,+16}` (with timestamps). Fit flow to valid tracks, not camera pixel motion; retain per-patch residual flow for rotation about a stationary centroid. Convert world→robot base via calibrated hand–eye + FK/tracked relative camera pose, or to current gravity-level nav coordinates. Unknown base transform → view-0 coordinates and a validity flag, **not** oracle extrinsics. No separate contact, waypoint-bank or analytic control stack.
7. **Fusion:** project C patches + camera/point/ray/depth/confidence features to width 4096. Add `tanh(g)·W(geometry)` to matching Qwen visual embeddings; initialize `g=0`, not both `g` and `W=0`. Gated residual cross-attention reads the 32 slots at layers 16/24; gate those writes at zero too, with no extra visible prefix at initialization. Keep Qwen's 32 decoder layers (24 DeltaNet, 8 full attention). Dense head losses train C while gates open. Both QA and policy then read instruction-conditioned hidden states that contain geometry.
8. **Input modes:** single image → identity reference, no pair-pose/flow targets; synchronized views → bidirectional set attention with a declared reference and camera IDs, no artificial time differences. Streaming → windows of 8 observed frames with 2-frame overlap; align windows in their overlap, update the same 32 slots by soft confidence-weighted read/write. Keep bounded local attention/KV; reset per episode, suppress unsupported pose links, unroll ≥2 windows for gradient tests. Offline 64/96-frame QA can scan windows; at decision time consume only `t≤now`. A future-frame perturbation must not change an earlier action. Long-horizon retention is a test, not an architectural guarantee.
9. **Action heads:** primary LIBERO proof uses the same QwenOFT readout on instruction-conditioned taps in both arms: identical action queries, proprio and 7-D action chunks. FlowExpert is a compatible alternative, not a second required run: `precompute_memory(taps={12,16,24}, geo_tokens=slots, detach_backbone=False)` → flow-matching action loss. For the matched comparison expose geometry **through taps**, no candidate-only head input. `navrun` reads the same taps with a native action/stop head; fit action CE and optional auxiliary polar subgoal regression, execute the same primitive interface in both arms. No parsed pixel click/waypoint solver. Each downstream adaptation starts independently from the **same sealed base hash** and exports one self-contained policy, not a chain of models.
10. **Precision:** retain all 24 `linear_attn.A_log` + 24 `linear_attn.norm.weight` tensors in fp32 at load, mixed-precision forward, optimizer update, FSDP all-gather and export/reload. Preserve other kernel-required fp32 values per implementation. BF16 elsewhere; fp32 SE(3), scale solves, normalization and recurrent sensitive math. Inspect actual forward dtypes; upcasting an already rounded export cannot recover precision. A finite three-step run does not establish VLA stability.

## Curriculum and split contract

**One immutable manifest before decoding or API upload.** Canonicalize physical room/visit/rescan, video/take/segment, subject and robot episode. Hash source, frame IDs, crop/K transform, time cutoff, teacher version and parent checkpoint. Apply the same deny set to imagery, labels, replay, teacher caches, mining, prompts and paraphrase/twin descendants. Unknown ID or missing authority file → quarantine. Group train/dev splits **before** making twins.

- Block `BENCH_v2`, `ReSTI` ScanNet `scene0000..0149` including rescans, 100 Waymo + 119 Omni6D sources, `R0_dev` 100, `dev-S1`, `K1-heldout` (pin both rowset files), `withheld-80`, all `VSTI-450` source rooms, OSI-150/DSI-1000 source videos and all augmentations, Ego-Exo4D 41 eval takes, HD-EPIC 128 prereg rows/12 subject IDs. No LIBERO/+Cam test trajectories or R2R-CE val/test scenes in pretraining. Block both R0 partitions in 1B/2/SFT; only Stage-3 RL may whitelist `R0-rl` 272 **minus every other exclusion**. Zero intersections; all positive, alias, missing-list and unknown-ID canaries must behave correctly.
- Existing Point4D OSI/STI stores are **schema/eval fixtures**, not a 492-clip training set. Ten validated clips show 0.018–0.033 m static residual under 15–53 m ego travel, not validated contact labels. Audit ancestry before choosing the LM: step-544 lineage with the 75 overlapping ReSTI rooms cannot support a clean all-ReSTI claim. Use an audited clean Qwen base for that claim or explicitly score the lineage-clean subset. Disclose unknown foundation-model exposure separately.
- **E05 v2, training factory only.** Hydrogen mines contact sheets/distractors; Neon/Carbon author train-only questions; Argon and Carbon independently box positive and absent frames without GT hints. Require agreement IoU ≥.90 on the *same instance*, veto disagreements; use SAM 3 offline for eroded foreground targets, never rectangle fill. Sample 40% micro-positive, 30% verified empty, 30% ordinary/clutter for the grounding pilot. Report recall on **all** candidates by area/domain, disagreement and rejection rates, not just mean accepted IoU.
- Release v2 shards only after receipts for all eight audit items: **(1)** RGB-only inspect, genuinely queried OOF misses, measured parallax angle ≥15° **and** baseline ratio ≥.20 **and** frame gap ≥2; **(2)** remove 48-scene/102-candidate caps, check requested yield; **(3)** ≥120 s request timeout and error accounting; **(4)** scratch-buffered logs, one cap poll; **(5)** pinned required K1 lists + distinct R0 canaries; **(6)** per-capture half/full raster containment, reject unknown; **(7)** reject disjoint instance boxes; **(8)** yaw positive-left, true best frame retained, randomized instance order, count all instances, remove canned echoes. Math parity and masking alone clear none of the oracle-input defects.
- Start C=16 on spare Gemini capacity. Measured 3.46 accepted traces/min, .0277 MB/s, 187 timeouts/512 calls: no promise of 500k in 72 h. First target 500 clean rows, then 5k traces/10k boxes as measured yield permits. Independent 200-row stratified audit: ≥97% correct referent/answer, zero privileged fields/split hits, p10 box IoU vs independent GT ≥.70 on micro-positives. Scale concurrency only with timeout <10%, headroom on total bandwidth, and verified new scenes; quarantine a failed stream, keep clean streams running.

## Falsification and release ledger — proposed thresholds, not measured gains

- **G0, implementation:** all exclusion/identity tests pass; 0 mismatched joins and 0 external calls; action-only gradient paths pass; gate-zero parent logits agree at matched layout (fp32 test max error ≤1e-5). Require all 48 fp32 tensors and zero nonfinites on train/export/reload, including ≥1,000 downstream optimizer steps. Real peak <72 GiB/H100, <45 GiB on a 48 GB smoke. On OOM reduce views by streaming or checkpoint activations, not by substituting a dummy trunk.
- **G1, native geometry:** 53/53 finite fixed-view captures; mean clip-median rotation ≤11°, rotation<15° ≥82%, translation direction ≤14°, δ1 ≥90%, gravity ≤6°. On 90° E0 diagnostic: depth ratio .95–1.05, AbsRel ≤.13, δ1 ≥85%, leg error ≤.10 m; repeat on untouched episodes and report 60°/110° separately. Failure → localize depth shape vs scale, predicted vs supplied K, degree/radian and mirror errors. Never substitute the teacher at inference.
- **G2, grounding/4D/memory:** native DEV-MASK 117 MRA ≥63.8 vs served 55.81, <1% anchor recall ≥85%, empty-frame FPR ≤5% at a train-dev-fixed threshold. Require moving-track EPE ≥20% below zero-flow on clean disjoint tracks **and** median static drift ≤.04 m. On blocked-source-free dev analogues require reversal gap ≤10 pp without lowering standard accuracy; ≥5 min revisit accuracy ≥5 pp over last-window-only inference on identical clips. Zero dependence on future pixels. Fail → report failed scope; no claim of general 4D/long-horizon reasoning.
- **G3, language reads geometry:** direct no-tool QA ≥+3 pp paired on R0-dev over parent, each static/dynamic/cross-view/long dev slice no worse by >1 pp. On solvable truth-flipping pairs require ≥80% both correct and ≥10 pp drop when **only** slot values are shuffled across matched scenes. If SFT passes, retain RL only for ≥+2 pp paired dev twin accuracy without >1 pp clean-QA loss. After seal: one official read on VSI-5130, ReVSI-999, VSTI-450, lineage-clean ReSTI, DSI by augmentation, Ego-Exo4D 2A/2B and HD-EPIC by time gap; report actual coverage, not a pooled score across incompatible metrics.
- **G4, strictly stronger base:** same `d5_s0` 5 demos/task (50 total), 10k updates, 500 LIBERO-Spatial + 376 zero-demo `+Cam` episodes; same fixed 10% R2R-CE train subset and `val_unseen_600_s0`, using `rand100` for integration only, never for tuning. Proposed wins vs matched reference: **≥+8 pp Spatial SR, ≥+12 pp +Cam SR, ≥+5 pp nav SR and positive SPL delta**; post-FT direct QA drop ≤1 pp. Compare both against B0/N0 and B1/N1 where clean matched receipts exist; a provider/controller change cannot establish backbone transfer.
- Pair episodes and initial states; report task-/scene-clustered 95% intervals, adjust the three primary SR tests (Holm), count timeouts/crashes as failures. Require positive adjusted lower bounds on all three SR gains to claim superiority; inconclusive ≠ win. Profile batch-1 RGB arrival → first executable action **including both visual paths**: target p95 ≤150 ms/chunk on deployment hardware, report chunk length and fresh-observation Hz separately. An offline score gain with a slow policy is not a real-time VLA pass.
