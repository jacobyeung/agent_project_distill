## 1. North-Star Unified Architecture ("Spatial-V2")

`Spatial-V2` collapses all valid Wave-2 mechanisms onto **one shared geometry/depth/pose/4D-flow representation** and **one persistent 3D instance store** aligned to `Qwen3.5-9B`'s actual topology (`32` layers: `24` Gated DeltaNet + `8` full-attention layers at `{4, 8, 12, 16, 20, 24, 28, 32}`). Speculative components are explicitly decoupled from the core trunk so every gain is cleanly attributed.

**Physical & Interface Contracts Enforced Across Every Module:**
1. **Honest Latency Accounting:** Every reported latency includes ViT + geometry + LM-L16 noun-span compute + slot lifting + action head. Distinguish **chunk execution rate** (`30 Hz` with FK re-projection) from **fresh-observation forward rate** (`8–10 Hz` at `<120 ms` full forward); never claim `30–50 Hz` fresh-observation control while consuming LM `taps 16, 24, -1`.
2. **Exact Projective & SE(3) Physics:** Uniform world scaling leaves intrinsics $K$ unchanged; only physical image crop/resize updates $K \to K'$. Temporal reversal uses frame-consistent inverse transforms $T^{\text{rev}}_{i\to j} = (T^{\text{fwd}}_{j\to i})^{-1}$, never naively negating camera-frame translation. Native MuJoCo raster mirror uses `fx < 0, diag(-1,1,1)`. `scale_donor` / $\gamma_{\text{scene}}$ stays optimizer-protected (`0.000%` drift).
3. **Strict Causal & Transitive Constraints:** Streaming memory (`VQ3D`/mobile nav) truncates input strictly to $t \le t_q$ *before* pose, gravity, or loop-closure computation; note LM context is $O(1)$ (`<=1,800` tokens) while frame index and pose graph grow $O(T)$. Slot clustering enforces transitive same-frame must-not-link (MNL) graph constraints (no two observations from frame $t$ may share a merged cluster).
