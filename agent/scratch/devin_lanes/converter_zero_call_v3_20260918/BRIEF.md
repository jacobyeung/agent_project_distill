## Change 1 — teacher narration is never rendered and never defers
The survey shows every unmapped qualification is a `teacher_qualification` record holding the teacher's free first-person process narration ("my attention has now been drawn...", "we're converging towards a stable solution..."). That is planner narration, which the design review classes as a Tier-I defect when it reaches a student target (v3/1600). The pronoun gate was right to stop it; the error was deferring the whole trace.
(i) Classify each `teacher_qualification` record deterministically. STRUCTURED CAVEAT: it names at least one object identity present in the trace's measurement records AND a frame or a measured quantity AND a reliability, visibility or scope condition (for example unreliable, occluded, truncated, partially visible, not visible in frame, approximately, image-relative, vertical only). Everything else is NARRATION: first-person process talk, plans, confidence chatter, "converging", "my attention", "let me", "we should". Write the classifier rules and the harvested examples per class to `LANE/out/QUALIFICATION_WORDINGS.md` (harvest source above).
(ii) NARRATION is skipped by policy: not rendered, never a deferral, counted in a Tier-II measure `narration_skipped_fraction` per trace.
(iii) STRUCTURED CAVEAT renders through the normalization table (`QUALIFICATIONS`/`TOOL_WORDING` in `zero_call_policy.py` or a new v3 table) in third person with object, frame, reference, affected quantity and exceptions preserved verbatim. If the caveat text carries a raw coordinate triple, tool or variable name, path or code, the rendered line refers to the measurement instead (for example "the centroid measured for the door in frame 12") and never copies the raw value; the numbers already appear as observation lines bound to the measurement record. A caveat that cannot be rendered without inventing scope is skipped with Tier-II `caveat_unrenderable`, not deferred.
(iv) There is no generic-rendering path for narration. Reconcile `QUALIFICATION_ARTIFACT` (zero_call_records.py:10) with the trace-level `ARTIFACT`/`TRIPLE` lint (Change 2) so a line that clears the qualification gate cannot later trip `artifact_lint`.
(v) Tests: a narration sample is skipped with the Tier-II count and the trace still renders; a structured caveat renders with scope preserved; a caveat containing a triple renders without it and passes the lint; no qualification code path returns `qualification_unmapped` or any deferral on the harvested set.
