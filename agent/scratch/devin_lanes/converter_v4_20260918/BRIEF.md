## Required design (orchestrator decisions 2026-09-18)
1. Grounded fact sheet stage (call A). From the bound evidence the model produces a structured sheet, each entry bound to exact evidence spans by the existing citation resolver: (a) an identity table: every object mentioned gets one stable descriptive name for the whole target, with the evidence instance ids and frames it rests on; ordinal names ("first whiteboard") are allowed only as defined in this table; (b) observations, each with its scope (which object, which frames, which image or world direction); (c) corrections, each as (superseded statement, corrected statement, why it matters); (d) qualifications, each with its referent (which observation or measurement it limits) and its direction or frame scope; (e) calculations with operands, units, precision and result; (f) failed or inconclusive checks that the teacher relied on (for example an unsuccessful search that changed the plan). A deterministic check rejects the sheet if any later entry refers to an identity not in the table or if a qualification has no referent.
2. Explanation stage (call B) writes the student explanation from the fact sheet only. Every claim cites fact-sheet entries, which carry the evidence spans; claims may not introduce identities, scopes or persistence absent from the sheet. Corrections appear as the corrected fact, with what was corrected when it bears on the answer. Completed methods appear as visual and spatial reasoning (what was compared, measured or estimated and how), never as tool steps, code, variables, data shapes, plans, personas or thought summaries. The final answer must equal the native bare answer byte for byte.
3. Semantic self-review stage (call C) applies the seven checks of `REVIEW_SPEC_v3.md`, claim by claim, to the candidate against the evidence and the sheet, in the reviewer's schema. Any failed check triggers one bounded repair of call B (with the failing findings fed back) followed by one more call C; a second failure rejects the qid with the findings recorded. The self-review's verdicts are stored with the candidate and are part of the review bundle; they never substitute for the independent review.
4. Length: each call gets the 32,768 output budget; the sheet and the explanation are separate calls precisely so long traces like 3919 fit. If any call still ends on MAX_TOKENS, requeue once with an instruction to condense the sheet (merge repeated per-frame observations into ranges), then reject.
5. Keep every v3 guard that still applies (artifact lint, exact citation resolution, qualification coverage, first-appearance evidence, rounding and unit checks). They become defense in depth behind the structural stages.
