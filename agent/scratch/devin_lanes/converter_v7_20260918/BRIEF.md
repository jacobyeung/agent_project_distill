## Design (from the review, binding)
1. Typed measurement records: deterministic code builds, from every tool call and return pair in the archive, a record with value(s), units, identity (instance id and identity-table name), frame or frame set, reference frame (image or world), and the exact source lines of the call and the return. Frame-availability lists are a separate record type and never serve as support for a measurement.
2. Stage A (the only production model call): select the substantive spatial facts, calculations, uncertainty and corrections into a compact sheet; each observation names the record id it rests on (the code verifies the record's identity, frame and value match the observation); each qualification carries the exact source text and one student-facing version with identical scope (object, frames, reference, affected quantity, exceptions); each calculation has a typed operation, operands as record or observation ids, operand order, the recorded result, the question's required precision, and the recorded sign or direction convention with its condition (for example "Z-up; positive means left").
3. Deterministic rendering: Observations rendered from records and the sheet's student-facing wording verbatim; Calculations rendered from typed templates with one explanatory sentence each stating geometric meaning and the convention with its condition; Reasoning rendered from operation-specific templates that connect the recorded result to the question's threshold or option mapping (numbers may come from observations, calculations and the question); the answer byte-identical to the native bare answer. Templates for unknown operation types defer the trace rather than improvise.
4. No stage B or stage C calls in production. Deterministic checks decide: record binding present and consistent for every observation; qualification scope fields unchanged between source and student version; every number in the target traces to a record, a calculation or the question at the required precision; artifact lint for actual tool, planner, code, path, mask and coordinate-triple content (not for ordinary words like "assume" or "convention"); answer equality; native final never cited. A failed check allows one targeted extraction repair with the finding attached; a second failure defers the trace.
5. Tier I / Tier II reporting: the pipeline records, per target, the deterministic Tier-I checks above and Tier-II measures (fraction of observations with own-record binding, qualifications carried verbatim, calculations with explanatory sentence); it never admits anything.
