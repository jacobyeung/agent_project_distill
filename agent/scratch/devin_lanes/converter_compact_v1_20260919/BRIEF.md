## Why
Tonight's first distilled OneThinker-8B evaluation showed that the current format-A targets (median 4,739 tokens, 50 enumerated observation lines, no stop cue before a bare answer line) teach the student the enumeration but not its termination: it loops inside the observation block until the 16,384-token decode cap on a tail of items, and the targets are far too long to decode in practice. A design lane measured the alternatives and specified a compact format that keeps only the observations the teacher's calculations actually use, counts them, and closes with a fixed marker: median 467 OneThinker tokens, p90 1,752, about 12 times shorter than format A, with the perceptual-knowledge content intact. Read `/data2/jjyeung/agent_project_data/distillation_orchestrator_20260918/claude_design_compact_targets/out/DESIGN.md` first (sections b to d are the specification), then `EXAMPLE_RENDER_B.txt` beside it, then the loop evidence in `/data2/jjyeung/agent_project_data/distillation_orchestrator_20260918/claude_base_reeval_instructed_onethinker/out/CAPPED_OUTPUT_ANALYSIS.md` and the target statistics in `/data2/jjyeung/agent_project_data/distillation_orchestrator_20260918/claude_target_enumeration_stats/out/TARGET_ENUMERATION_STATS.md`.

## Build
Write `student/compact_targets/compact_counted_v1.py` (plus tests under `student/compact_targets/tests/`) in the worktree. For every qid in the recovery set that also appears in `diagnostic_set_obs/candidate_index.jsonl` (the reviewed pool; report the count), render:
1. Selection: `C` = lines with `kind == "calculation"`; `R` = the ids named in any `Operands: ...` clause of `C`; emit `S` = lines with `kind == "appearance"` union lines with id in `R`, in file order. Convention lines and unreferenced qualification lines leave the visible text and go to the sidecar.
2. Layout, exactly: line `Observations (N)` with N = |S|; then `k. <student_text>` for k = 1..N, student_text byte-identical to the source; if C is non-empty, line `Derivations (M)` then `k. <student_text with the "Operands: ..." clause replaced by "Uses observations i, j.">` using the new 1..N indices; then the literal line `End of reasoning.`; then the final line, which is the bare answer exactly as `row.answer` (letter or number), nothing after it and no trailing newline, the same terminal convention as format A. This deviates from DESIGN.md's `Answer: X`: the evaluation instruction and parser expect the answer alone on the last line, and the target must match that.
3. Citations: default variant has no `[E##.L##]` brackets in visible text; the sidecar `lines.json` (one record per emitted line: index, id, record_id, record_sha256, citations, kind) keeps the target verifiable against the typed records. Implement a `--derivation-citations` flag that emits the brackets on derivation lines only, and render that variant for the 16 pilot qids only (under `pilot_variant_derivation_citations/`) so the independent reviewer can rule which the Tier I checks require.
4. Admission checks, each failure deferring the qid with a reason to `DEFERRED.jsonl` while it stays in the denominator: (1) every emitted student_text byte-identical to its source; (2) the multiset of numeric tokens in the visible target is a subset of the selected sources' numeric tokens; (3) every emitted line resolves to a record_sha256 in the sidecar; (4) header counts equal emitted counts and indices run 1..N contiguously; (5) every `Uses observations k` index exists; (6) `End of reasoning.` occurs exactly once, immediately before the final answer line, nothing after; (7) the existing Tier I checks recorded in the source `checks.json` still pass for the emitted lines; (8) length at most 1,536 OneThinker tokens, else `over_budget`; (9) |S| = 0 deferred as `no_selected_observations`.
5. Outputs under `out/diagnostic_set_compact/`: `candidate_index.jsonl` in the exact schema of the reviewed index (`postprocess` = `compact_counted_v1`, new `config_sha256` over your renderer configuration, `generation_commit` = your worktree commit, `row_path`, `row_sha256`, `sha256`), `targets/<qid>/{row.json,target.txt,lines.json,checks.json}` where `row.json` copies `student_input` and every other field from the format-A row and replaces `target`; `DEFERRED.jsonl`; `STATS.md` with the token-length distribution (min, p10, median, p90, p99, max) overall and per question_type, the observation and derivation counts, and the deferral counts by reason; `PILOT_SAMPLE_16.json` (16 qids stratified across question types, seed 17, with both variants' paths) and `REVIEW_PROMPT_compact.md` for the independent reviewer (compare each emitted line with the typed records, check the count headers, the derivation references and the closing lines, and rule on sidecar versus inline citations).
