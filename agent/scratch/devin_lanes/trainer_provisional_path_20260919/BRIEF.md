## Changes (all behind one explicit flag; clean path untouched)
1. CLI flag `--provisional-diagnostic <LABEL>` on `diagnostic train`, the held-out evaluation, and `benchmark_eval generate` and its scoring step. LABEL is one of `ZERO_CALL_DIAGNOSTIC_PENDING_REVIEW`, `ZERO_CALL_V4_DIAGNOSTIC_PENDING_REVIEW`, `FREEFORM_CN_DIAGNOSTIC_PENDING_REVIEW`. Without the flag every module behaves exactly as today (assert with a byte-identical behavior test on the clean path).
2. Candidate loader `load_provisional_candidates(index_path, label)`: reads the row format above or the `zero-call-diagnostic-candidates-v3` container, verifies each target file's sha256, validates each row's `student_input` against `accepted-grounded-detailed-targets-v1`'s row contract, and returns training rows tagged `provisional_diagnostic=LABEL`. `load_accepted` is not modified.
3. Provisional split protocol: scene-disjoint split with seed 17 and a holdout fraction argument (default 0.1 in this mode), its digest recorded as `PROVISIONAL_SPLIT_SHA` in the run manifest; `SPLIT_SHA` and the fixed cohort remain for the clean path. Held-out evaluation in this mode runs on the provisional holdout.
4. Lease host binding: in this mode the training and evaluation leases bind to the current hostname and the GPU UUID probed at launch (`nvidia-smi --query-gpu=uuid -i <idx>`), both written into the lease file and re-checked at start; without the flag the existing fixed binding stays. No identity is ever forged.
5. Evaluation contracts: in this mode `generate` and scoring accept a `student-publication-v1` receipt carrying `benchmark_trained_diagnostic=true` and `provisional_diagnostic=LABEL`, and every generation file, score file and results table is tagged with the label and the words "diagnostic, provisional". In this mode the code refuses to write a `clean-student-training-v1` receipt and refuses to load one (test asserts both refusals). The clean-path checks are unchanged.
6. Publication: adapter directory, `PUBLISHED.json` and manifests carry the label; the report says so.
