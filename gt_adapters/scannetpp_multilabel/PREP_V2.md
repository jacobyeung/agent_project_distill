This package prepares ScanNet++ GT assets for isolated validation. It does not authorize collection. Teacher, prompts, tool interfaces, camera alignment, OBB conversion, depth rendering, occlusion, and the 32-visible-pixel proof threshold retain their pinned implementations.

`instance_mesh.npz` contains each source vertex and face once. `membership_instance_ids` lists every official ID in increasing order, including IDs with no faces. `membership_face_offsets` and `membership_face_indices` encode CSR rows of sorted, unique source face indices. Rows may overlap. `segment_ids`, `segment_offsets`, and `segment_instance_ids` encode each annotated segment's sorted set of official IDs. Vertex segmentation assigns a face to the intersection of its three vertex memberships. Face segmentation assigns its memberships directly. `source_provenance.json` preserves complete official segGroups, while the runtime OBB file retains the donor half-extent convention.

The loader supports both the explicit sparse schema and the pinned single-membership schema. The instance renderer selects sparse faces before applying its unchanged face cap, rasterizer, occlusion tolerance and mask handling. Scene depth retains the donor's source-vertex splat implementation; membership never duplicates geometry or scene-depth inputs.

Proof candidates include every instance with at least one official face, sorted by (face count, official ID). A conservative mesh test rejects only meshes entirely behind the donor near plane. The renderer tests candidates until one produces at least 32 visible pixels or the list is exhausted, independently at slots 1 and 17. No OBB corner test, minimum face-count gate, or attempt cap applies.

Set `PYTHONDONTWRITEBYTECODE=1`, `CUDA_VISIBLE_DEVICES=''`, and `PREP_CONTRACT_SHA256` to the externally reviewed SHA-256 of `PREP_CONTRACT.json` before calling `prepare_gt_scene.py`. The contract pins every other package file; its own digest belongs in the external execution receipt. Use the environment pinned in the validation manifest. Run fixtures with `PREP_FIXTURE_ROOT` pointing under the training DATA root and `python -B test_prep_v2.py`; fixtures retain all outputs without deletion.
